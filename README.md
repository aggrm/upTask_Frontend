# 🚀 upTask – Frontend

Frontend de **upTask**, una aplicación de gestión de proyectos y tareas que permite organizar trabajo, asignar colaboradores y hacer seguimiento del progreso desde una interfaz moderna y reactiva.

Este repositorio contiene únicamente la parte **cliente (Frontend)** de la aplicación.

---

## 🧰 Stack Tecnológico

- React
- TypeScript
- Vite
- React Router DOM
- Axios
- Tailwind CSS
- Context API

---

## ✨ Funcionalidades

- Registro y autenticación de usuarios
- Gestión de sesión mediante tokens
- Creación, edición y eliminación de proyectos
- Creación y gestión de tareas por proyecto
- Asignación de colaboradores
- Protección de rutas privadas
- Consumo de API REST
